ok tolon# 🎵 Folder Musik - GINSUL SNACK

Letakkan file musik background di folder ini dengan nama:

**`bgmusic.mp3`**

## Rekomendasi Musik
- Musik instrumental ceria / cheerful
- Gamelan pop Indonesia
- Lo-fi beats santai
- Durasi: 2-5 menit (akan loop otomatis)

## Cara Mendapatkan Musik Gratis
1. **YouTube Audio Library** → [studio.youtube.com](https://studio.youtube.com) → Audio Library
2. **Pixabay Music** → [pixabay.com/music](https://pixabay.com/music/)
3. **Free Music Archive** → [freemusicarchive.org](https://freemusicarchive.org)
4. **Incompetech** → [incompetech.filmmusic.io](https://incompetech.filmmusic.io)

## Format yang Didukung
- `.mp3` (direkomendasikan)
- `.ogg`
- `.wav`

Letakkan file dan pastikan namanya persis: **bgmusic.mp3**
